DEFENSIVE WORKFLOW

What it does

01 / DETECT

Authentication monitoring

Reads new SSH authentication failures from the systemd journal and records private source and username metadata for investigation.

02 / CORRELATE

Brute-force detection

Groups repeated failures by source and time window, raises HIGH severity incidents, and uses cooldowns to avoid duplicate alert spam.

03 / RESPOND

Temporary SSH blocking

Uses a dedicated nftables table to apply time-limited TCP/22 blocks after safety checks, without affecting the public website.

04 / VERIFY

File integrity

Maintains trusted SHA-256 baselines for protected configuration files and reports unexpected changes without automatically trusting them.

05 / BASELINE

Services and ports

Checks expected systemd services and externally bound TCP ports so unexpected host-state changes can be surfaced quickly.

06 / ALERT

Discord notifications

Sends private notifications for correlated HIGH events and automated blocks while keeping credentials and detailed attack data off the website.
