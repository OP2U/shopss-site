SHOPSS Desktop

A lightweight Windows desktop companion built around a clean SHOPSS visual system: live widgets, customizable desktop organizer zones, tray controls, and optional self-hosted server monitoring.

Download v1.0.0 View GitHub ↗

Windows 10/11 x64 • Installer release • MIT licensed

Desktop preview

The personal setup uses organizer zones on the left and lightweight live widgets on the right.

Organizer zones, clock widget, and live server widget running together on an ultrawide desktop.

Desktop Organizer

  • SCHOOL, PROJECTS, MISC, and custom zones.
  • Drag-and-drop files and folders into real backing folders.
  • Resizable zones with saved positions and sizes.
  • Optional automatic sorting rules per zone.
  • Hidden scrollbars with normal mouse-wheel scrolling.

Widgets

  • Clock and date.
  • Optional server health and resource monitoring.
  • Layout locking and click-through behavior.
  • Desktop-only mode and opacity controls.

Stack

C# WPF .NET 10 Windows Inno Setup

Lightweight by design

The desktop organizer reacts to filesystem events instead of repeatedly scanning the Desktop. Server monitoring is optional, and the clock/server refresh intervals are intentionally low-frequency.

Optional server monitoring

The public build ships with no personal server endpoint configured. Users can connect their own compatible JSON status endpoint from the tray menu, or simply leave the server widgets disabled.

Release

v1.0.0 is the first public baseline release, packaged as a Windows installer with source available on GitHub.

PROJECT INFO

Open-source Windows utility

SHOPSS Desktop is released under the MIT License. The project uses Microsoft .NET/WPF, while Inno Setup is used to build the Windows installer.

The installer is currently unsigned, so Windows SmartScreen may show an unknown-publisher warning on some systems. Source code and release files are available through GitHub.
